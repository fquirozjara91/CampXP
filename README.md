# CampXP

World of Warcraft (WoW Forever) addon that tracks your XP buffs — **Camp Benefits**, **Well-Rested** and **XP food** — and shows how much experience you're losing without them.

- Addon source: [`CampXP/`](CampXP/) (copy this folder into `Interface/AddOns`)
- Full description and commands: [`CampXP/README.md`](CampXP/README.md)
